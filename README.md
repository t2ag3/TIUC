## 🚧 なぜ？ — 背景と課題

> **本日は工事中です。**<br>
> **Today is under construction.**
>
> ― 京都・二条城で実際に使われていた案内。何がヘンか、わかりますか？

AI翻訳は、街中に "ヘンな日本" を増やしています。

文化に根ざした料理名や固有名詞は、AIでも間違えがち。  
一度看板やメニューに刷られた誤訳は、**AIが賢くなっても、誰かが気づいて直さない限りそのまま残り続けます。**

「趣深い誤訳」もあるけれど、「混乱を招く誤訳」も存在している。  
「趣深い誤訳」はみんなで愛でたい、でも「混乱を招く誤訳」は改善したい…。  
 誤訳を正しく修正するには、高度なバイリンガルの力が必要…  


TIUCなら、**どんな人でも参加可能。**  
1. 日本語表記の意味やその文化的背景が分かる人は、写真の投稿や写真の日本語説明の追加で貢献  
2. 訳が表す意味やニュアンス、違和感のあり／なしが分かるネイティブは、投稿された写真の分類や違和感の解説で貢献
3. 日本語も外国語もバッチリなバイリンガルは、誤訳のヘンな理由解説と修正案の投稿で貢献

そして、**都内は人材の宝庫。**  
日本人も訪日・在留外国人もバイリンガルも、TIUCに参加できる人材が、都内には大勢います。  

| 指標 | 数字 |
|---|---|
| 都内の在留外国人 | **80.1万人**（都道府県別で最多・全国の19.4%） |
| 前年比 | +8.5% |
| 主な言語コミュニティ | 中国語 30.5万 / 韓国語 9.3万 / ネパール 6.4万 / ベトナム語 5.9万 |

## 🎮 あそび方 — 3つのアクション

語学力がなくても大丈夫。撮るだけでも立派なプレイ。得意な人は、直しにまわろう。  
**上下も順番もなく、求める能力の "種類" が違うだけ。どこからでも参加できます。**

### 📸 ACTION 01 — 撮る
- **だれでも・語学力不要**
- 街で見かけた外国語のメニューや看板を撮って投稿。ゲームのタネになる。
- `+10 XP / 投稿`

### 🔍 ACTION 02 — チェックする
- **その言語のネイティブ**
- 「あまり見ない表現かも？」をワンタップで判定。テンポよく連続プレイ。
- `+5 XP / 判定`

### ✍️ ACTION 03 — 案を出す
- **両言語がわかる人**
- 正しい訳と「なぜヘンか」を提案。採用されれば大きな経験値。
- `+50 XP / 採用`

> 写真の品質チェックやシチュエーション入力など、能力に応じた細かなタスクにも参加できます。

## ⬆️ 育てる — レベルと実績

遊ぶほど上達し、実績が増える。判定の精度や採用された修正で、あなたのレベルが上がります。

| 要素 | 内容 |
|---|---|
| 🏆 **実績（トロフィー）** | 「誤訳ハンター」「◯◯語マイスター」など、活動に応じた称号。取ると限定キャラがもらえることも。 |
| 🗺️ **マップコレクション** | 自分が直したスポットが地図に灯る。エリアを制覇していこう。 |
| 🔥 **ストリーク** | 毎日の判定でストリークを伸ばす。続けるほどボーナス経験値。 |

> レベル（上達）と、下の「キャラ収集」は別のしくみ。上達は実力の証、収集は集める楽しみとして分けています。

## ✨ 集める — キャラクター図鑑

プレイするほど、動物キャラがドロップ。集めて、合成して、自分だけの図鑑をつくろう。

### レアリティ（背景の豪華さで表現）

| レアリティ | 背景イメージ | 例 |
|---|---|---|
| ⭐ コモン | 無地 | スズメ、シバイヌ など身近な定番 |
| ⭐⭐ レア | 単色グラデ | メジロ など |
| ⭐⭐⭐ エピック | 青空＋光の粒 | カワセミ、マヌルネコ など意外な人気者 |
| ⭐⭐⭐⭐ ユニーク | 虹色にキラキラ | 合成で到達する最上位 |
| 🌈 スペシャル | きらめく特別背景 | 合成では手に入らない。**街を直すと出会える** |

### ドロップと合成

| きっかけ | もらえるもの |
|---|---|
| 投稿・判定などの日々のアクション | **通常ドロップ**（レアはやや低確率） |
| レベルアップ | **レア確定** |
| 修正が採用される | **レア確定** |
| 実績・街への貢献 | **スペシャル**キャラ |

- **合成**：同じキャラが重なったら合成でレアリティアップ（同一キャラ昇格）。
- コモン ⭐ ×2 → レア ⭐⭐ ／ レア ⭐⭐ ×3 → エピック ⭐⭐⭐ … と、上のレアほど必要枚数が増えていく。
- 手に入れたキャラは、自分のアイコンに設定できる。

## 🌏 社会へのインパクト — 街から誤訳が減る循環

TIUCは「アプリの中で正しい訳をつくる」だけでは終わりません。  
**現物が直り、報告されて初めて、街から誤訳が実際に減ります。**

```
① 見つける          街の外国語表記を撮影・投稿
      ↓
② 確定させる        ネイティブ＋バイリンガルが正しい訳を確定
      ↓
③ 現物を直す        店・施設が実際に看板／メニューを修正   ┐
      ↓                                                  │ 現実世界のループ
④「直したよ」報告    修正完了を報告                        ┘
      ↓
⑤ 街で可視化        誤訳が減った証がマップに灯り、参加者みんなの成果に
      ↓
   （①へ戻る）
```

④の「採用・報告」がループを閉じると、①②③に関わった全員のスコアが跳ね上がります。  
= **街が実際に良くなったときだけ、最大の報酬が出る**設計です。

この循環が回るほど、街の誤訳は減り、住む人も訪れる人も気持ちよく過ごせる東京に近づきます。

## 🛠 技術構成

| 領域 | 採用技術 |
|---|---|
| 実行基盤 | Cloudflare Workers |
| データベース | Cloudflare D1 |
| 画像ストレージ | Cloudflare R2 |
| AI（一次フィルタ・OCR） | Cloudflare Workers AI |
| 地図 | OpenStreetMap © OpenStreetMap contributors |
| キャラクター画像 | ドット絵（AIによる生成） |

- Cloudflareの無料枠を中心に、低コストで構築・運用。
- 投稿画像はWorkers AIでセンシティブ判定・人物の映り込み判定などの一次フィルタリングを行い、**最終的な訳の正誤判断は人が担う** human-in-the-loop 構成。
- AIは「足切りと下書き」まで。翻訳の正しさをAIに断定させず、文化に根ざした表現はネイティブと精通者が確定させます。
